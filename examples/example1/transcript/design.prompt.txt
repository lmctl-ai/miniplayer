REQUIREMENTS
Create a TypeScript project: a command line note taker. Notes are plain .txt files stored in a single directory (default ./notes, overridable with NOTES_DIR). Note names are validated (letters, digits, dash, underscore only) so a name can never escape the directory. Exit code 0 on success, non-zero with a message on stderr on failure.
